Read Japanese anywhere on your screen.

AnkiPop is a Japanese OCR popup dictionary for manga, visual novels, games, websites and hardcoded video subtitles. Look up words, translate sentences, learn grammar, and make Anki flashcards without retyping what you see.

Download AnkiPop Read documentation

Downloads are available for Windows, macOS and Linux. New fork features have been tested primarily on Windows.

Built for Japanese reading and immersion

Screen OCR dictionary

Hover Japanese text in games, manga, browser pages, or video subtitles to get quick lookups, even when the text isn't selectable.

One-key Anki cards

With AnkiConnect running, press Alt+A to save a word with reading, meaning, sentence context and optional screenshot or audio.

Sentence translation

Press Alt+T to translate a Japanese sentence using Google Translate. This feature requires an internet connection.

Japanese grammar help

Press Alt+G for offline explanations of recognized grammar patterns from JLPT N5 through N1.

Manga mode

Switch to a mode designed for vertical speech bubbles, with popups that avoid covering the rest of the text.

Across desktop apps

Screen-based OCR can work with visual novels, emulators, websites, videos, and other windows. Accuracy depends on the OCR backend and text layout.

Get started

  1. Download the latest release for your operating system and follow the installation instructions.
  2. Start AnkiPop and let it download its first-run dictionary and OCR models.
  3. Hover over Japanese text to see definitions. Use Alt+T to translate and Alt+G to explain grammar.
  4. To create cards, install Anki and AnkiConnect, then press Alt+A over a word.

AnkiPop does not require an account for local dictionary lookups. Online translation and optional card extras use external services; see the README for details.

Frequently asked questions

Can AnkiPop read Japanese text from manga images?

Yes. It uses OCR to read Japanese text visible on screen, including manga images. Manga mode is designed for vertical text. Results vary with image quality and OCR settings.

Can I use it for Japanese games and visual novels?

Yes. The screen OCR dictionary is intended for text visible across desktop applications, including games and visual novels, without requiring text hooks.

Does it automatically create Anki cards?

Cards are created when you press Alt+A over a selected word. You'll need Anki and the AnkiConnect add-on running.

Does it work offline?

After first-run setup, dictionary lookups and local grammar explanations work offline. Google Translate sentence translation requires a network connection.

How is AnkiPop related to MeikiPop?

AnkiPop is a GPL-3.0 fork of MeikiPop, adding integrated Anki cards, sentence translation, grammar explanation, and manga-specific improvements.
